# ONEIC Dashboard — لوحة تحكم التحصيل

## 🚀 النشر على Vercel (5 دقائق)

### الخطوة 1 — حمّل Node.js
- اذهب إلى: https://nodejs.org
- حمّل الإصدار LTS وثبّته

### الخطوة 2 — تأكد من التثبيت
```
node -v
npm -v
```

### الخطوة 3 — ثبّت المكتبات
```
npm install
```

### الخطوة 4 — اختبار محلي (اختياري)
```
npm run dev
```
افتح المتصفح على: http://localhost:5173

### الخطوة 5 — النشر على Vercel
1. أنشئ حساب مجاني على https://vercel.com
2. أنشئ حساب على https://github.com
3. ارفع هذا المجلد على GitHub كـ Repository جديد
4. في Vercel → "New Project" → اختر الـ Repository
5. اضغط Deploy ✅

**الرابط يكون جاهزاً خلال 2 دقيقة!**

## 🔄 تحديث الداشبورد يومياً
- افتح الداشبورد في المتصفح
- اضغط "📂 رفع ملف يومي"
- اختر ملف الـ .xls الجديد
- البيانات تتحدث فوراً تلقائياً ✅
